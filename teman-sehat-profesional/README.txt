TEMAN SEHAT - WEBSITE EDUKASI PERTEMANAN SEHAT

CARA MENJALANKAN:
1. Ekstrak file ZIP.
2. Buka Visual Studio Code > File > Open Folder.
3. Pilih folder teman-sehat-profesional.
4. Install extension Live Server jika belum ada.
5. Klik kanan index.html > Open with Live Server.

CATATAN KEAMANAN:
Login ini hanya simulasi front-end untuk demonstrasi/tugas. Username dan password ada di JavaScript, bukan sistem keamanan untuk akun sungguhan. Untuk penggunaan nyata, tambahkan backend, database, dan penyimpanan password yang aman.

Refleksi disimpan di browser/perangkat yang sedang digunakan (localStorage), tidak tersinkron ke perangkat lain.
